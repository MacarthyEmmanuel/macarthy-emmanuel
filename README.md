# Macarthy Emmanuel Prince — Portfolio

Professional portfolio for Macarthy Emmanuel Prince, showcasing experience in scholarship research, content creation, SEO, social media, training, research, and team coordination.

## Live site

After enabling GitHub Pages, the portfolio will be available at:

`https://YOUR-GITHUB-USERNAME.github.io/macarthy-emmanuel-portfolio/`

## Publish with GitHub Pages

1. Create a new **public** GitHub repository named `macarthy-emmanuel-portfolio`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Click **Save**.
7. GitHub will provide your public portfolio URL.

No hosting service or paid domain is required.
